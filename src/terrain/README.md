# 程序化月面

地形按世界坐标确定性生成，参考月面观测特征，不对应某处真实高程数据。

- `noise.js`：固定种子的随机数和连续噪声。
- `craters.js`：数量可变的空间目录、连续尺寸分布、坑底、退化坑缘与重叠关系。
- `height.js`：区域起伏、不同尺度的坑与非周期月壤细节。

参考依据：

- [NASA：月球陨石坑](https://science.nasa.gov/moon/lunar-craters/)：小坑以碗状为主，中央峰和阶地属于更大尺度的复杂坑。
- [Minton 等，2019](https://arxiv.org/abs/1902.07746)：部分月海小坑的平衡累计尺寸分布近似满足 `N(>r) ∝ r^-2`，退化程度受后续撞击影响。
- [Sun 等，2018](https://data.boulder.swri.edu/ksinger/Sun_etal_2018_subkm_lunar_craters_Icarus.pdf)：亚千米新鲜坑的深径比约为 0.1～0.2，且随地形条件变化。
- [LROC：月海坑的光照对比](https://www.lroc.im-ldi.com/images/76)：月壤厚度和基岩会影响坑体形状，低太阳高度角会突出地表起伏。

分布指数作为小坑生成的近似；古老的大型洼地只用于构造区域背景，未按全球统计校准。密度、尺寸上限和年龄混合为探索体验选取；年龄参数表示形态退化，不代表测定年代。重叠处理只近似削弱同尺度的旧坑缘，不模拟完整撞击演化。
